--- THE ONE CORE BLOCKER: StrongRef.cpp (32-bit GC-handle redesign) ---
StrongRef packs (48-bit slot ptr | 16-bit index) into ONE pointer-sized
handle; static_assert(sizeof(uintptr_t)==8). On wasm32 a pointer is 32 bits
— can't pack both. Must stay ABI-consistent with src/jsc/Strong.rs (whose
32-bit path currently treats handle == raw slot pointer, index 0 — WRONG
for a multi-slot block).
  StrongRootBlock: JSCell in an IsoSubspace/MarkedBlock, capacity=960
  WriteBarrier slots; set/write/clear all need block+index for GC write
  barriers + occupancy bits.
  DESIGN for 32-bit (both sides): make StrongRefImpl a heap {block*, index}
  pair; handle = ptr to it. Rust Strong.rs get() derefs handle->block->
  slotAt(index) instead of reading handle as slot. Needs alloc/free of the
  pair (mind leaks). ~half-day focused task + testing. Core (GC handles used
  everywhere), so NOT excludable — this gates a working `bun run`.
