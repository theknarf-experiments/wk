# clap-template — a CLAP plugin compiled into a wk:clap component

Proof that an **unmodified CLAP plugin** can be compiled to a wk component via the
[`wk:clap`](../../crates/wk-server/wit-clap/world.wit) WIT world, so wk can host
the wider CLAP ecosystem.

## How it works

- `plugin-template.c` — the official minimal CLAP plugin, vendored verbatim from
  [free-audio/clap](https://github.com/free-audio/clap) (`src/plugin-template.c`),
  MIT. It exports a `clap_entry` global, like every CLAP plugin. An L/R-swap
  stereo effect with one note input.
- `clap-include/` — the vendored CLAP SDK headers (MIT; see `clap-include/LICENSE`).
- `shim.c` — the bridge. It implements the `wk:clap` `plugins` exports by driving
  the plugin's `clap_plugin` vtable, and presents a `clap_host` (log /
  thread-check / latency / state / params) that forwards to the imported wk
  `host` interface. `get_extension`'s dynamic negotiation is replaced by folding
  the core extensions into the exported resource, with `features()` reporting
  which the plugin actually implements.
- `gen/` — `wit-bindgen c` output for the `wk:clap` world (regenerated by the
  build; git-ignored).

Porting any other CLAP plugin is: point `build.sh` at its source(s) instead of
`plugin-template.c` — no plugin changes, just recompile + link the shim.

## Build

    mise run build            # -> clap-template.wasm (a wasm component)

Requires the shared toolchain from the repo root `mise.toml` (wasi-sdk,
wit-bindgen, wasm-tools). Emits a **reactor** component (`-mexec-model=reactor`)
that exports only `wk:clap/plugins`.

## Status

The component builds and validates (`wasm-tools validate`). The wk host-side
**drive path** — a CLAP node kind that instantiates the component and pumps
`process()` from the audio thread, converting a wk MIDI wire to CLAP input events
and routing the audio output — is not implemented yet.

Marshalling is by value (events as a tagged list, audio as channel lists); a
shared-memory fast path can replace `process` later without touching the WIT.
